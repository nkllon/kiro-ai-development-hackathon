# Prompt Writing Patterns

## Core Pattern: Keep It Simple, Stupid
When you want another agent to do something:
1. **State the mission clearly** - What do you want done?
2. **Give context** - Why does this matter?
3. **Specify deliverables** - What exactly should they produce?
4. **Reference examples** - Point to similar work
5. **Set success criteria** - How do we know it's done?

## Anti-Patterns to Avoid
- ❌ Meta-philosophical spirals about the nature of coordination
- ❌ Recursive loops about observing observers observing
- ❌ Over-engineering simple requests into complex systems
- ❌ Asking "but what does it all MEAN?" when someone just wants a spec

## The Golden Rule
**If you find yourself using the word "meta" more than once in a prompt, you've probably gone too far.**

## Template
```
**Mission:** [What you want done]
**Context:** [Why/background] 
**Task:** [Specific deliverables]
**References:** [Examples to follow]
**Success:** [How to know it's done]
```
