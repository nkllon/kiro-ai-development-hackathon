## 🚀 Quick Start

### 1. Install Dependencies

Both notebooks require several Python packages. Install them with:

```bash
# Quick install (recommended)
pip install structlog pydantic redis matplotlib numpy

# Or install all project dependencies
pip install -r ../../requirements.txt
pip install structlog  # This package is missing from main requirements
```

### 2. Launch Jupyter

```bash
# From the project root
cd examples/notebook

# Option 1: Jupyter Notebook (classic)
jupyter notebook

# Option 2: JupyterLab (recommended)
jupyter lab

# Option 3: VS Code
# Just open the .ipynb file in VS Code with Jupyter extension
```

## 🐛 Troubleshooting

### ModuleNotFoundError: No module named 'structlog'
```bash
pip install structlog
```

### Mermaid diagrams not rendering
- Mermaid is supported in GitHub and many Jupyter environments
- If not rendering, diagrams are still described in text
- Try JupyterLab with the mermaid extension

### Import errors from constellation_orchestrator or beast_mode
- The notebooks will fall back to demonstration mode
- All concepts and visualizations will still work
- Check that you're in the correct directory (`examples/notebook/`)

### Matplotlib/NumPy not available
- Install with: `pip install matplotlib numpy`
- Notebooks will provide text-based summaries if visualization unavailable
