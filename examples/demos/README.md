# Demo Examples

This directory contains demonstration scripts and interactive examples showcasing the Beast Mode Framework capabilities.

## Comprehensive Demo Suite

### 🧠 AI Memory Palace Demonstrations
The AI Memory Palace eliminates the "50 first dates" problem by maintaining persistent context across AI assistant interactions.

- **`ai_memory_palace_demo.py`** - Comprehensive demonstration of all AI Memory Palace features
- **`ai_memory_palace_interactive.py`** - Interactive CLI for exploring AI Memory Palace capabilities
- **`ai_memory_palace_benchmark.py`** - Performance benchmarking and scalability testing
- **`AI_MEMORY_PALACE_README.md`** - Detailed documentation and usage guide

### 🔄 DAG Orchestration Demonstrations
DAG orchestration manages the execution of tasks with dependencies, ensuring proper order and parallelization.

- **`dag_orchestration_demo.py`** - Comprehensive demonstration of DAG orchestration capabilities
- **`dag_orchestration_interactive.py`** - Interactive CLI for creating and executing custom DAGs
- **`DAG_ORCHESTRATION_README.md`** - Detailed documentation and usage guide

### 🔧 ReflectiveModule Pattern Demonstrations
ReflectiveModule provides comprehensive observability, health monitoring, and systematic error handling.

- **`reflective_module_demo.py`** - Comprehensive demonstration of ReflectiveModule pattern
- **`reflective_module_interactive.py`** - Interactive CLI for exploring ReflectiveModule capabilities
- **`REFLECTIVE_MODULE_README.md`** - Detailed documentation and usage guide

#### Quick Start
```bash
# AI Memory Palace demos
python examples/demos/ai_memory_palace_demo.py
python examples/demos/ai_memory_palace_interactive.py
python examples/demos/ai_memory_palace_benchmark.py

# DAG Orchestration demos
python examples/demos/dag_orchestration_demo.py
python examples/demos/dag_orchestration_interactive.py

# ReflectiveModule demos
python examples/demos/reflective_module_demo.py
python examples/demos/reflective_module_interactive.py
```

#### Features Demonstrated

**AI Memory Palace:**
- Execution Pattern Learning: Store and learn from execution patterns
- Project Context Management: Multi-project context with session awareness
- Performance Monitoring: Health checks and comprehensive statistics
- Graceful Degradation: Robust error handling and fallback mechanisms

**DAG Orchestration:**
- Dependency-aware task execution
- Parallel processing with multiple strategies
- Intelligent scheduling algorithms
- Comprehensive error handling and monitoring

**ReflectiveModule:**
- Health monitoring and status reporting
- Performance metrics and operation tracing
- Graceful degradation capabilities
- Dynamic CLI interface generation

## Usage

Demo examples are designed to be interactive and educational. Each demo includes:

- **Clear documentation** explaining the demonstrated features
- **Sample data** for realistic testing scenarios
- **Performance metrics** showing system characteristics
- **Error handling** demonstrating robust operation
- **Interactive elements** for hands-on exploration

## Requirements

Most demos require:
- Python 3.8+
- Beast Mode Framework components
- Required dependencies (see individual demo files)

Some demos may run in simulation mode if full dependencies are not available.
