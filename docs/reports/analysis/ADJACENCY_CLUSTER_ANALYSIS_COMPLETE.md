2. **Finding clusters** - Groups of similar vectors

## 📐 **ADJACENCY MATRIX CALCULATION**

### **Similarity Calculation:**
- **Dimension-by-dimension similarity**: `1.0 - abs(val1 - val2)`
- **Weighted overall similarity**: Weighted average across all dimensions
- **Dimension weights**:
  - Technical Complexity: 0.2
  - Risk Level: 0.25
  - Uncertainty Level: 0.15
  - Resource Constraints: 0.1
  - Time Pressure: 0.1
  - User Expertise: 0.1
  - System Stability: 0.1

### **Adjacency Type Classification:**
- **Exact Match**: ≥ 0.95 similarity
- **High Similarity**: ≥ 0.8 similarity
- **Moderate Similarity**: ≥ 0.6 similarity
- **Low Similarity**: ≥ 0.4 similarity
- **Outlier**: < 0.4 similarity

---

## 🏗️ **CLUSTER DETECTION**

### **Cluster Formation Algorithm:**
1. **Start with unprocessed vectors**
2. **Find all vectors with high similarity** (exact match or high similarity)
3. **Create cluster if ≥ 2 vectors found**
4. **Mark all cluster vectors as processed**
5. **Repeat until all vectors processed**

### **Cluster Analysis:**
- **Centroid Calculation**: Average dimension values across cluster vectors
- **Variance Analysis**: Variance in each dimension within cluster
- **Cohesion Score**: How tightly clustered the vectors are
- **Separation Score**: How well separated from other clusters
- **Representative Vectors**: Vectors closest to cluster centroid
- **Internal Outliers**: Vectors that don't fit well within cluster

---

## 🎯 **OUTLIER DETECTION**

### **Outlier Identification:**
- **Not in any cluster**: Vectors that don't belong to any existing cluster
- **Distance calculation**: Distance to closest cluster centroid
- **Isolation levels**:
  - **Completely Isolated**: > 0.8 distance
  - **Moderately Isolated**: 0.5-0.8 distance
  - **Slightly Isolated**: < 0.5 distance

### **Outlier Analysis:**
- **Outlier Score**: Distance to closest cluster
- **Potential New Class**: Score > 0.6 suggests new class
- **Outlier Reasons**: Why this vector is different
- **Suggested Class Name**: Generated based on extreme dimensions
